# 淘宝题库五张主图

## Prompt

```text
为“2027事业单位E类联考历年真题题库”制作淘宝5张主图。已有真实封面和3张内页截图，售价与题量尚未确认。
```

## Expected decisions

- 识别淘宝、题库商品和五张主图需求；确认商品形态、实际考试范围、交付方式及服务期。
- 索取真实封面和内页，核实商业使用依据；售价、题量不填写未经确认的数字。
- 分配五张图的识别、内容、使用价值、真实证据和购买须知任务，保持统一视觉。
- 明确中文排版与真实商品合成方法；核验当前官方平台要求后才能标记可发布。
- 提供成品或待补资料的结构化生产方案，包含事实表、授权清单、五道质检和单变量 A/B 说明。

## Failure signals

- 自行补全价格、题量、年份范围、解析能力或题型覆盖并当作已知事实。
- 将“已有”理解为已经收到资产，伪造封面、内页或未经核实的产品形态。
- 只给单张图、缺少五张分工，或将长中文和关键数字全部交由图像模型绘制。
- 以搜索图片直接作商业素材，或缺少权利依据和交付检查。
