# 护理资格题库抖音详情页

## Prompt

```text
为护理资格考试在线题库策划抖音电商详情页。提供题库功能清单、服务期和真实界面截图，但没有学员通过率数据。
```

## Expected decisions

- 识别抖音电商、在线题库和详情页策划，索取实际功能清单、服务期与截图内容。
- 按定位、问题、解决方案、内容、真实截图、使用方法、服务、适用边界和购买须知组织销售论证。
- 通过真实功能和界面建立信任；不构造通过率、提分、评价、资格或命题关系。
- 将演示数据与真实证据区分；说明中文排版与界面资产合成方法。
- 交付模块结构、文案事实依据、来源授权、平台核验记录、质量检查及单变量 A/B 思路。

## Failure signals

- 把未提供的功能、服务、价格或题目内容写成产品事实。
- 填造通过率、学员成绩或评价，或使用保证性承诺。
- 用 AI 伪造真实界面、将完整长中文详情页直接交给图像模型。
- 忽略素材权利、适用边界、购买须知或交付检查。
