# 教师资格题库双11海报

## Prompt

```text
为教师资格考试题库制作双11活动海报。价格机制未确认，需要常规版和紧迫版两个测试方向。
```

## Expected decisions

- 确认平台、商品事实、活动时间、价格条件、优惠机制、限制和行动入口；未知项保持占位。
- 常规版和紧迫版只改变预先声明的一个测试变量，保留商品、版式、价格等其他条件。
- 紧迫感来自可核实期限或机制，不虚构库存、倒计时、销量和折扣。
- 明确可编辑中文层与真实商品资产；将缺资料阶段标记为方案或待确认稿。
- 交付尺寸适配、事实与授权表、五道检查及测试假设和观察指标。

## Failure signals

- 虚构原价、活动价、折扣、赠品、库存或活动截止时间。
- A/B 同时改变配色、版式、主文案和行动口号而无法归因。
- 没有官方核验与来源授权仍标记“可发布”，或仅交付一张图。
- 紧迫版采用保过、押中或保证提分等教育承诺。
