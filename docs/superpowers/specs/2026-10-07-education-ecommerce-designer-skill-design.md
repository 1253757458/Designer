# 国内教育电商平面设计师 Skill 设计规范

## 目标

创建并安装一个名为 `designing-education-ecommerce-graphics` 的执行型 Codex Skill。它面向淘宝/天猫、京东、拼多多、抖音电商和小红书等国内平台，为教育培训、题库课程及备考资料完成需求分析、销售视觉策划、主图组、详情页、活动海报和平台适配素材，并在交付前执行真实性、广告合规、知识产权与生产质量检查。

首版采用单一综合 Skill，通过按需加载的参考文件覆盖不同工作模式；暂不拆成多个独立子 Skill。

## 成功标准

- 能从自然语言需求判断平台、商品形态、目标人群、购买阶段和交付物。
- 能把教育产品信息转换为以点击、理解、信任和购买决策为目标的视觉方案。
- 能调用 Codex 原生 ImageGen 生成背景、场景和辅助视觉，并正确处理真实商品资产与中文信息。
- 能生成主图组、详情页模块和活动海报的可执行设计方案及成品。
- 不虚构教材封面、题目、界面、教师资质、学员评价、成绩、排名、通过率或命题关系。
- 不输出教育广告禁用的保证性承诺。
- 每项外部素材均有可验证的商业使用依据；不能确认授权的素材不得进入成品。
- 交付包含平台尺寸、事实依据、授权记录、合规检查和 A/B 测试说明。

## 非目标

- 不代替用户确认商品事实、价格、活动机制、资质或授权。
- 不默认发布、投放或上传成品到任何平台。
- 不把搜索到的图片、竞品页面或社交媒体内容直接用作商业素材。
- 不承诺作品一定通过平台审核；规则易变化，正式交付前需要核验最新官方要求。
- 不在首版实现独立的图片生成 API、付费素材库集成或自动投放系统。

## 运行流程

1. **识别任务**：确定平台、商品形态、交付物、活动场景和期望指标。
2. **检查输入**：核对品牌资产、商品事实、价格机制、真实截图、授权状态与输出尺寸。缺少会改变成品真实性或合法性的资料时，先索取资料或明确使用占位方案。
3. **形成策略**：明确目标用户、备考阶段、核心焦虑、单一核心卖点、支持证据和行动指令。
4. **提出方案**：给出主视觉方向、信息层级、配色、字体、图像策略与 A/B 测试变量，先让用户审核高影响选择。
5. **生产素材**：使用真实商品资产；调用 ImageGen 生成背景、场景或原创辅助元素。长中文、关键数字和证据型内容不依赖图像模型直接绘制。
6. **组合与派生**：完成中文排版、商品合成和平台尺寸适配。不同平台按浏览情境重组信息，不只做机械裁切。
7. **五道质检**：执行信息准确、转化清晰、视觉可靠、权利完整、平台与广告合规检查。
8. **交付**：输出成品、尺寸版本、可编辑结构说明、事实依据、素材授权清单、风险项与 A/B 建议。

## 岗位认知模型

### 商业层

先理解商品形态、价格、促销机制、购买阶段和转化目标。主图主要解决点击与快速识别，详情页解决理解与信任，活动海报解决行动。

### 用户层

识别考试类型、备考阶段、基础水平、可投入时间和核心焦虑。题库的价值不是题量本身，而是帮助用户练习、查漏、理解解析、复盘错题和安排进度。

### 信息层

按“核心承诺—支持证据—内容功能—适用对象—购买行动”建立层级。一张图承担一个主要沟通任务；关键信息在缩略图状态下仍可识别。

### 视觉层

根据商品与活动选择可信专业、效率冲刺、轻松陪伴或权威出版等方向。字体、色彩、留白、对比、商品图和辅助图形必须服务同一视觉概念，不机械套用红底黄字或信息堆叠。

### 平台层

货架平台优先商品识别、卖点与决策信息；内容平台优先场景、阅读钩子与原生感；促销场景强化活动机制、条件与截止信息。同一创意需要重新组织，而非简单裁切。

### 风险层

设计前后检查广告真实性、教育培训禁用承诺、平台规则、版权、字体授权、肖像权、商标、个人信息和 AI 生成素材风险。证据不足的数字、排名、通过率、命题关系或评价不得进入成品。

## 核心设计原则

- 以信息理解、点击和购买决策为目标，不把“好看”作为唯一标准。
- 每张图只承担一个主要沟通任务，首图不堆满课程内容。
- ImageGen 优先生成背景、场景和辅助视觉，不直接承担长段中文与关键事实排版。
- 教材封面、题目截图、教师资质、成绩数据、用户评价和产品界面必须来自真实、获授权、可核验的资产。
- 默认提供一个主方案和一个只有明确变量差异的 A/B 方案。
- 平台规则属于动态信息；正式交付前查询最新官方规则，并记录核验日期与来源。
- 用户品牌要求优先于通用审美偏好，但不能覆盖真实性、可读性、合规和权利要求。

## 商业素材权利门槛

图标、图片、字体、人物、品牌标识和 AI 生成内容均需通过权利检查：

- 只使用来源明确、许可证覆盖预定商业用途的素材。
- 不从搜索结果、竞品页面或社交媒体直接复制素材。
- 第三方素材记录来源链接、作者、许可证、下载日期、署名要求和限制条件。
- 字体必须核验商业授权范围；无法确认时使用许可明确的替代字体。
- 人物照片必须具备肖像授权；涉及未成年人时采用更严格的授权和隐私标准。
- 品牌 Logo、教材封面、试卷截图和产品界面只使用用户提供或已证明授权的真实资产。
- AI 生成内容需符合所用模型的商业使用条款，并检查近似商标、知名角色、在世艺术家风格模仿、疑似水印和训练数据复现风险。
- 无法确认授权时，停止使用该素材，改为自行生成、使用许可明确的替代品，或要求用户提供授权证明。
- 每次交付附带素材来源与授权清单，不以“网上可用”或口头声明代替证据。

## 交付物标准

### 主图组

默认规划五张：

1. 商品识别与单一核心卖点。
2. 题量、科目、年份、题型等真实内容范围。
3. 刷题、解析、错题复盘等使用价值与学习路径。
4. 真实内页、界面、资质或可验证数据形成的信任证据。
5. 适用人群、交付形式、服务周期和购买须知。

首图必须在缩略状态下清晰识别商品名称与核心价值；不得虚构纸质书、设备界面、名师或考试关系。

### 详情页

默认销售论证链为：

```text
首屏定位 → 用户痛点 → 产品解决方案 → 内容与题型结构
→ 真实页面或内页 → 使用方法与学习路径 → 功能或服务说明
→ 适用与不适用人群 → 可验证信任证据 → 版本/有效期/交付方式
→ 售后与购买须知 → 行动收口
```

没有事实依据或购买价值的模块应删除。演示数据必须明确标注；产品截图不得由 AI 伪造为真实界面。

### 活动海报

按“看见—理解—行动”组织：第一焦点为活动主题或用户收益，第二层为商品与活动机制，第三层为时间、价格条件、适用范围和必要说明，只保留一个主要行动指令。价格、折扣、赠品和截止时间必须由用户确认。

默认生成常规版与紧迫版两个测试方向，但二者只改变预先声明的测试变量。

## 交付包

- 成品图与平台尺寸版本。
- 可编辑源文件；若工具无法产生源文件，则交付结构化版式、文字、色值、字体和位置说明。
- 使用的商品原始素材清单。
- 文案与事实依据表。
- 素材来源与商业授权清单。
- 平台规范、广告合规和真实性检查表。
- A/B 版本差异、假设和建议观察指标。
- 无法核实、需要用户确认或存在残余风险的项目。

## 质量门槛

1. **信息准确**：名称、科目、年份、题量、价格、服务和版本一致。
2. **转化清晰**：三秒内能识别卖什么、适合谁和核心价值。
3. **视觉可靠**：层级明确、中文无错字、缩略图可读、图像与商品一致。
4. **权利完整**：字体、图标、图片、人物、品牌与 AI 素材均可追溯。
5. **合规可交付**：无保过、保证提分、虚构押题、虚构资质或未经证实的数据。

任一门槛未通过时，不把产物标记为“可发布”；应给出修正项或等待用户补充证据。

## 验证策略

实施采用针对 Skill 的 RED–GREEN–REFACTOR：

1. 在没有新 Skill 的情况下，用真实任务测试默认行为，记录其在需求澄清、教育合规、版权来源、中文排版和交付完整性上的缺口。
2. 编写最小可用 Skill 与参考文件，使同类任务能够稳定完成策略、生产与五道质检。
3. 用至少三类场景复测：题库商品主图、长详情页、限时活动海报。
4. 加入高压反例：用户要求使用网上找到的图片、要求写“保过/押中原题”、缺少真实截图却要求伪造产品界面。
5. 修复测试暴露的缺口，运行 Skill 结构校验，并人工检查来源、授权和触发边界。
