# 接单与销售视觉策略

先形成能驱动制作的简报。已提供的信息直接整理，无须让用户重复回答；缺项只追问会改变真实性、权利、购买决策或生产方式的内容。必需输入是正式成品的门槛，缺项时仍可交付注明用途的策略草案或占位版式。

## 必需输入

按“平台—交付物—用户—考试—商品形态—价格/活动—证据—品牌—授权—尺寸”逐项检查。每项记为已确认、待确认或有理由的不适用。

| 输入 | 需要取得的内容 | 缺项处理 |
| --- | --- | --- |
| 平台 | 平台名、商品类目、商品页/内容推广/付费广告场景 | 先作概念方案；正式适配前确认场景与现行官方要求 |
| 交付物 | 主图组、详情页、海报或店铺素材；数量、用途、期限 | 可提出默认建议，标为假设，不据此发布 |
| 用户 | 目标人群、备考阶段、基础、时间约束、主要购买疑问 | 用已知商品提出受众假设，请确认；不编造用户调研结论 |
| 考试 | 名称、科目、适用年份/版本；不涉及考试时记不适用 | 未确认的考试名称、年份、适配范围不落图 |
| 商品形态 | 纸质资料/数字题库/录播课/直播课等；获取方式、内容范围、有效期、服务与售后 | 关键购买信息等待事实；不可将数字商品虚构为纸质书或设备 |
| 价格/活动 | 成交价、标示价格依据、条件、赠品、适用范围、起止时间；无活动则记无 | 可省略非必需价格区；要展示的数字和条件须确认，不能造原价或紧迫性 |
| 证据 | 商品清单、真实封面/内页/截图、功能说明、可核验资质和数据出处 | 未提供的证据位置标为待补；不生成冒充真实证据的内容 |
| 品牌 | 正式名称、已授权 Logo、既有色彩/字体要求；无品牌资产则明确 | 可建议通用配色与文字标识；品牌身份、机构资质不推测 |
| 授权 | 每项素材的来源、权利人、许可/授权文本、商业用途范围、限制与署名 | 不用待授权素材，改用有依据的替代素材或等待证明 |
| 尺寸 | 使用位置、比例、像素、文件格式/体积、安全区及规则来源 | 可按用户指定尺寸做草案；平台正式版本须动态核验，不套跨境规则 |

商品与素材都分配可引用的编号：事实记录为“字段—值—依据/版本—确认状态”；素材记录为“资产类型—来源链接/文件—作者/权利人—许可证或授权证明—商业用途与限制—署名—取得日期—检查状态”。沿用实际资产类型，如截图、扫描页、实拍，不混称。

## 可选输入

| 输入 | 用途 |
| --- | --- |
| 现有页面、历史素材、品牌规范 | 延续识别体系，找出信息缺位和重复任务 |
| 真实浏览/点击/转化数据及统计口径 | 确定优化重点和测试指标；不推断未测得的提升幅度 |
| 用户访谈、客服常见疑问、退货原因 | 调整购买论证、适用边界与购买须知 |
| 竞品链接、风格参考 | 分析信息与视觉取舍；仅供研究，不作为成品素材授权 |
| 编辑工具、印刷需求、源文件格式 | 确定生产与交付方式；工具无法生成源文件时给结构化版式说明 |

## 决策边界

| 情形 | 可以继续的工作 | 必须等待或替换的内容 |
| --- | --- | --- |
| 缺少设计偏好、模块数量或主方案方向 | 提出合理假设，说明原因，做可逆草案 | 首次高影响选择尚未确认时等待；已有授权覆盖的选择不重复确认 |
| 缺少题量、年份、售价、活动或服务事实 | 无相关断言的策略、明确占位版式 | 这些事实落图前取得可核验依据；替代文案里的功能也逐项确认 |
| 缺少字体、图标、人物或商品资产授权 | 使用许可明确的替代品，推进其他模块 | 未授权素材进入成品；“网上找到”“用户说能用”不等于授权证明 |
| 请求教育结果保证或暗示命题关系 | 删去禁用表达，基于已确认产品内容重写 | 不以“提供通过率证据”“有退款条款”“已授权”作为放行理由 |
| 平台现行规格或商品准入无法核实 | 输出草案、待核验清单 | 不能标可发布；历史公示通知仅作定位线索 |
| 请求上传、发布或投放 | 完成已授权的设计与交付准备 | 外部操作需要明确授权，设计委托本身不自动包含发布 |

先判断商品是出版物、软件题库还是培训服务，记录广告与类目规则的适用范围。教育培训结果保证、命题人员参与暗示及推荐证明禁限参见[《广告法》第二十四条](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/fgs/art/2023/art_5474cf75173c45d6a0379730fb4e8d97.html)（核验：2026-10-07），完整判断加载 [compliance.md](compliance.md)。教师介绍、学员照片或评价先检查是否构成禁用的推荐证明；真实且有授权也不能自动放行。退款只表达已核验的售后条件，不能借退款包装考试结果保证。

## 商业、用户、信息的决策模型

| 层 | 要回答的问题 | 对设计的影响 |
| --- | --- | --- |
| 商业 | 卖什么、怎么买、服务多久、当前购买阶段？ | 主图解决点击与快速识别；详情页解决理解/信任；海报解决行动和活动条件 |
| 用户 | 为哪类考试、哪个备考阶段、何种基础与时间约束设计？ | 只选与该用户相关的产品价值；受众假设与已证实功能分开记录 |
| 信息 | 哪个已证实价值最值得首先看见，什么能支持它？ | 单一核心卖点 → 支持证据 → 功能/范围 → 适用边界 → 行动；一张图一个主要任务 |
| 视觉 | 哪个方向能清楚传达商品而不制造身份或效果暗示？ | 用 [education-visual-system.md](education-visual-system.md) 选方向、层级与图像策略 |

题量是内容范围，不能直接等同于考试效果；练习、解析、错题复盘等价值只在商品实际提供时使用。多张主图应补齐内容范围、使用价值、真实证据和购买须知，不反复展示同类内页。详情页按购买疑问挑选模块，缺事实或无购买价值的模块删除；具体分工见 [deliverable-playbooks.md](deliverable-playbooks.md)。

## 策略输出合同

制作前交付一份紧凑策略表，字段可注明待确认，但不能省去证据和权利状态。

| 字段 | 必须包含 |
| --- | --- |
| 商业任务 | 平台/场景、交付物、购买阶段、目标指标 |
| 适用人群 | 考试与备考阶段、基础/时间约束、适用与不适用边界、假设状态 |
| 单一核心卖点 | 一个已确认的商品价值；用商品内容/功能表达，不用学习结果保证 |
| 支持证据 | 对应事实编号和真实资产编号；标出待补项，禁用表达不能改记成待补证据 |
| 信息分工 | 每张图/模块的主要任务、必需购买信息、行动指令 |
| 视觉方案 | 一种主方向、配色角色、字体授权依据、商品/背景策略 |
| 生产方式 | 最终答复必填：ImageGen 可生成的背景/原创辅助视觉；必须取自真实资产的封面、内页、界面与证据；后期可编辑中文、关键数字与条件。仅策划或占位草案同样区分三类，本次不生成则注明未调用 |
| 权利与规则 | 素材记录、类目适用范围、平台来源与核验日期、未决项 |
| A/B | 一个命名变量、A/B 具体值、固定项、假设与观察指标 |
| 制作与交付 | 尺寸版本、成品/可编辑结构、事实表/授权表/检查表及当前状态 |

## 单变量 A/B 合同

默认主方案 A 与备选 B 只改一个预先命名的变量。只测试主标题时，固定按钮文字、配色、商品图、价格/条件、版式、字体、尺寸、其他文案与投放条件；紧迫语气也只能使用真实已确认的截止信息。若用户要多个差异，拆为独立测试或标明探索性对比，不能称为可归因的单变量 A/B。

例：商品确认有错题整理功能，变量为“主标题表述”，A 为“集中复习错题”，B 为“从错题开始复盘”；其余元素一致。假设是两种价值表达对点击的影响，主图观察点击率，详情页/海报按实际目的观察购买或行动指标。交付前列出实际差异；多出按钮、强调色或模块变化则修正。没有测试数据时不宣称转化提升。
