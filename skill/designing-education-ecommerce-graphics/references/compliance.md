# 广告、事实与商业素材发布门槛

接单、文案改写和成品检查都执行本文件。先区分出版物、软件题库、教育培训服务及其组合，再记录平台、类目、使用场景、受众和适用规则；不能仅凭商品名排除教育培训广告要求。适用范围不清时记“待确认”，取得当前官方规则或针对该情形的专业复核后再判断。来源、访问边界和动态项见 [source-notes.md](source-notes.md)，平台检查另见 [platform-specs.md](platform-specs.md)。

以下证据清单、权利状态与阻断流程是本 Skill 的操作门槛，不是主管机关的审批结论。通过本次检查不保证平台审核通过或不存在其他法律问题。

## 1. 教育培训广告：检查整幅表达

依据[《广告法》第二十四条](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/fgs/art/2023/art_5474cf75173c45d6a0379730fb4e8d97.html)（2021 年修正文本，访问：2026-10-07），检查文字、人物、Logo、徽章、证书、截图、标题与小字共同形成的意思：

| 禁限 | 可执行检查 | 发现后的处理 |
| --- | --- | --- |
| 以升学、考试通过、获得学位学历/合格证书、教育培训效果作结果保证，包括暗示 | 是否把购买/学习与必然录取、拿证、提分等结果相连？数字、成功案例、退款机制或前后对比是否暗示保证？ | 删除保证及其视觉暗示，改为已证实的内容、功能或服务边界；证据、授权与免责声明均不能解除该禁限 |
| 宣称或暗示相关考试机构、其工作人员或命题人员参加教育培训 | 是否借考官身份、机构标识、内部材料、命题团队或类似布局暗示参与关系？ | 移除关系暗示，使用真实内容范围与合法来源说明；即使身份或关系真实也不能作为放行理由 |
| 以科研、学术、教育机构，行业协会、专业人士或受益者作推荐证明，包括使用其名义或形象 | 教师/专家、学员评价/成绩、机构 Logo 是否承担“推荐购买、证明效果或质量”的作用？ | 移除禁用推荐证明，改用可核验的真实商品内容和功能展示；真实学员或肖像已授权也不自动放行 |

第一项禁止的是**保证性承诺**，并非禁止一切学习目标或内容说明。可讨论适用阶段、学习任务与真实教学安排，但须核验事实及整体语境；不能把“保证拿证”换成“拿证目标”后继续通过画面暗示必然结果。教师的课程职责或身份介绍也不能仅因出现教师就一律判禁，须分别核验真实性、是否暗示考试参与及是否承担推荐证明；无法判断时保持待确认。

### 高风险表达是信号，不是完整判断

词表未命中也可能违规；命中时先检查整句和图像，不仅替换关键词。下表替代表述仅是写法方向，实际功能仍须证实，不能原样自动落图。

| 表达信号 | 核验与改写原则 |
| --- | --- |
| 保过、必过、保证提分 | 识别结果保证并移除；若确有相应功能，可描述“按科目练习”“解析与错题复盘”。不能改成“几乎必过”或靠小字免责 |
| 押中原题 | 检查是否保证未来考试命中、暗示命题参与或捏造历史数据；改为有来源、有使用权且确实提供的“历年题目整理”或“题型练习”，不保留命中暗示 |
| 内部题、命题组 | 核验整体是否暗示考试机构/命题人员参与。企业内部自编练习不等于考试内部资料；如属前者，以真实自编来源说明，去除误导性命名和机构视觉 |
| 零基础逆袭 | 检查是否以具体成绩、上岸画面、时间或无条件适用暗示保证；如确有基础内容，改述基础模块及适用条件，不能替换成“零基础也必过” |
| 高通过率、学员上岸、名师推荐 | 先过效果保证、命题参与和推荐证明禁限；不能把统计证据、用户授权或教师证书当作广告许可 |
| 不过退款、签约保障 | 退款事实与结果保证分别检查；不能用退款包装保过承诺。仅表述已核实的售后条件、适用范围与申请方式，并去除整体结果保证暗示 |

[江苏教育培训违法广告典型案例](https://www.samr.gov.cn/zt/ndzt/2025n/ggf/alzs/art/2025/art_869d7d22c7b64a329ba5916bd172f2cc.html)展示了通过率和考官团队的相关风险（访问：2026-10-07）。案例用于核对具体风险，不将案例罚款或某个词机械套成所有情形的法律结论。

## 2. 事实与最低证据矩阵

每项落图主张建立记录：`事实编号 | 字段和值 | 商品/SKU与版本 | 证据文件/URL | 统计口径和有效期 | 确认人/日期 | 确认状态 | 广告判断 | 引用图/模块`。证据须可追溯并匹配本次商品；口头保证、模型推测、竞品文案和生成图片不能独立证明事实。

下表是制作前的最低材料要求。事实确认与广告允许是两次检查：达到材料门槛仍可能因禁限不得展示。数据引用的真实性、出处和适用范围，以及商品/服务、赠品的清楚说明，依据《广告法》第八、十一、二十八条；具体取证字段为本 Skill 的核验方法。

| 字段 | 最低证据 | 落图与核验边界 |
| --- | --- | --- |
| 题量 | 对应版本的题目清单/后台导出；计数方法、去重规则、科目分项与统计日期 | 区分题目数、套卷数、解析数；不能累加重复题或把计划新增量算成已交付 |
| 年份/版本 | 商品版本记录、目录与适用考试说明；声称适配新考纲时有对应官方考纲和对照 | 区分出版/更新年与考试适用年；未完成新版不能标为已更新 |
| 科目/范围 | 当前目录、课程/题库清单及纳入/排除说明 | 只列真实包含范围，“全科”“全覆盖”逐项核验，不把一部分SKU写成全套 |
| 更新频率 | 已执行更新日志；未来承诺另有商家确认的服务条款、安排和期限 | 历史更新不能单独证明“每日更新”“永久更新”；明确截至日期和服务范围 |
| 解析覆盖 | 对应版本的解析清单、覆盖分母/分子和抽查原始页面 | 区分答案与解析、文字与视频；少量样例不能证明全部题目都有解析 |
| 教师身份 | 可核验资格/身份文件、实际授课关系与课程安排；经历主张有对应证明 | 文件隐私脱敏；不虚构职称、学校合作或编委身份。先检查是否为考试参与暗示或禁用推荐证明 |
| 用户评价 | 可回溯原始评价、真实商品/版本与时间；商业展示及个人信息的许可依据 | 不伪造、拼接或用AI代写成真实用户体验。教育培训受益者推荐证明不得以真实性放行；可改用商品内容证据 |
| 通过率 | 考试/届次、统计周期、分母/分子、样本纳入排除、原始结果和计算记录 | 不能把已证实历史统计推成未来结果；须先判是否构成保证或禁用推荐证明。判不清则不展示，保持待确认 |
| 排名 | 原始发布者、完整报告/榜单、统计范围/期间、指标及方法、对应商品 | 不能从局部样本推成行业第一；证据不解除绝对化用语或其他广告禁限，另核验现行规则 |
| 价格/优惠 | 当前SKU/后台价格、活动确认记录、成交条件；划线/比较价有实际依据与口径 | 完整保留券、人群、数量、期限、叠加限制；不编原价、折扣、稀缺名额或倒计时 |
| 服务期 | 当前合同/服务条款与实际交付说明；起算、结束、设备/账号、更新范围 | 区分题库可用期、课程观看期、答疑期；不可用未确认的“永久”代替期限 |
| 退费/售后 | 当前商家与适用平台条款、办理路径、条件、时限、扣费和例外 | 不擅改为无条件退款；不能包装结果保证。条款冲突待确认，不自行选择更吸引人的版本 |
| 赠品 | 名称、品种/规格、数量、期限、取得条件与交付方式的活动依据；相关资产授权 | 商品图与实际赠品一致，限制靠近权益；不以教材、设备或服务图片制造未承诺的赠送印象 |

缺少、失效或互相矛盾的证据一律输出“待确认”，写明缺项及所需材料，并阻止标记为“可发布”。可选主张可移除后重新检查；关键购买事实不能靠删除逃过核验。不适用项须写理由；草案占位要在图内清楚可见，不能作为商品事实。

## 3. 商业素材权利检查

每个原始素材、生成输入和最终使用版本都有资产编号。用户提供、免费、已付费、公开可见或AI生成均不直接等于商业权利已核验。依据[《著作权法》](https://www.ncac.gov.cn/xxfb/flfg/flfg_532/202103/t20210309_50530.html)第十、二十四、二十六条，核对具体使用权、许可范围和例外条件；本流程不能仅凭“用于教育”就把商业商品广告视作课堂教学使用（访问：2026-10-07）。

| 资产类型 | 至少核验 |
| --- | --- |
| 图片/插画/纹理 | 原始来源、作者/权利人、商业广告和预定渠道/地区/期限、修改及再分发范围、署名；购买素材时核对具体套餐和订单，不把搜索缩略图当许可 |
| 图标 | 具体图标集/文件的许可证与版本、商业用途、署名和修改要求；包内品牌图标另查品牌权利，不能由代码开源许可推断 |
| 字体 | 字体发布者、准确家族/字重/版本和许可；分别核对成品使用、字体文件嵌入、修改和随源文件再分发。系统自带/装在电脑上不是许可证明 |
| 人物肖像 | 摄影作品权利与肖像使用同意分别核验，覆盖本次广告、用途、渠道、期限和修改。广告使用他人名义/形象取得事先书面同意；不把图库模特当真实教师/学员，也不合成真实人物作虚假证言 |
| 未成年人 | 年龄、监护关系及相应书面同意、商业使用范围、隐私保护；涉及不满14周岁个人信息，核验监护人同意和专门保护规则。不满10周岁不得作广告代言人；这不等于所有儿童画面一律禁止，但还须过教育推荐证明等检查 |
| Logo/商标/机构标识 | 权利人或授权链、品牌规范、用途/渠道/期限及修改边界；不把品牌公开页面、上游代码许可或真实合作直接当广告使用依据，不制造官方/考试机构参与印象 |
| 教材/试卷/题目 | 封面、内页、题目、解析、编排及所含图像分别核对权利和展示范围；“公开真题”、购买了一本书或拿到扫描件不能单独证明复制与广告展示权，不复制竞品封面/试卷 |
| 产品截图 | 产品方授权或可核验的自有权利、版本及原始界面；嵌入题目/图片/Logo的第三方权利与个人信息另查；脱敏并说明，不改成绩、评价和功能，截图不冒充实拍 |
| AI生成内容 | 生成工具/服务、生成日期、任务/输出文件、当时适用条款和商业用途范围；参考输入的权利、输出中的人物/品牌/作品相似性另查。工具允许商用不保证无第三方权利风险或可取得排他版权；禁止冒充真实封面、教师、截图、证书或成绩 |

肖像判断同时参考[《民法典》肖像权条款](https://www.cac.gov.cn/2020-06/01/c_15925617772683193.htm)，未成年人个人信息参考[《个人信息保护法》第二十五、二十八至三十一条](https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm)（访问：2026-10-07）。涉及真实人物资料上传到生成服务时，另核验处理目的、授权和适用的数据规则，不由广告肖像授权推断已允许该上传。

AI生成内容用于网络发布时，按[《人工智能生成合成内容标识办法》第十条](https://www.cac.gov.cn/2025-03/14/c_1743654684782215.htm)主动声明并使用传播服务提供的标识功能；不得恶意删除、篡改、伪造、隐匿规定标识（访问：2026-10-07，2025-09-01施行）。记录生成区域和已有标识，导出后检查；发布平台的具体标识方法交付前复核，未知则待确认。图内“概念示意图”标签不能代替适用的AI声明/标识流程。

### 授权台账与唯一状态词

字段保持以下名称和顺序；每项填写实值或明确待补内容。商业用途范围内写明本次渠道、广告/商品页、地区、期限、源文件交付/再分发与生成输入用途；限制和核验结论放入对应字段。

```text
资产 ID | 文件名 | 类型 | 来源 URL/提供方 | 作者/权利人 | 许可证或授权文件 | 商业用途范围 | 署名要求 | 修改限制 | 下载/接收日期 | 核验人 | 状态
```

状态只能为以下四种；不要另造“已授权”“默认可用”等状态：

| 状态 | 赋值条件与发布处理 |
| --- | --- |
| 已核验可商用 | 证据完整，覆盖本次具体用途，署名及其他许可要求已在该成品履行；仅这一种可无条件进入可发布成品。仍须过事实、广告、平台和视觉检查 |
| 限制使用 | 许可明确但有未满足或尚未核验的渠道、期限、修改、署名、再分发等限制；不得无条件进入可发布成品。满足具体用途要求并复核后更新为已核验可商用，保留原限制和变更记录；做不到则换素材 |
| 待补证 | 来源、权利人、授权链或用途范围缺证/存疑；不用该资产制作正式成品，取得材料或换可用资产，交付保持待确认 |
| 禁止使用 | 已明确不允许本次商业用途、已过期/撤销且无有效许可、或发现伪造/侵权等禁止理由；移除或替换，当前含该资产版本禁止发布，不能靠备注放行 |

复合素材的各层分别记账，不能用一张合成图的许可覆盖全部组件。更换用途、平台、版本、期限或交付字体/源素材时重新核验；保留许可原件与访问日期，不能只存“免费商用”截图。

## 4. 合并门槛与交付结论

每条风险记录 `位置/编号 | 问题 | 事实/广告/权利/平台门槛 | 依据 | 所需材料或替换动作 | 责任人 | 复核结果`。任何一道门槛失败都不能标“可发布”，不能通过平均分、主方案通过或用户接受风险来抵消。

| 检查结果 | 交付状态与动作 |
| --- | --- |
| 事实、授权或适用规则缺证/无法判断；存在未解决限制 | 待确认；列明所需材料，只继续无断言/有可用素材的草案或替代方案 |
| 已确认结果保证、命题参与暗示、禁用推荐证明、虚构事实或禁止使用资产 | 当前版本的发布结论为“禁止发布”；删除/重写/替换后重检。未修正时不得作为可发布广告交付，不把禁用表达列为“补证后可用” |
| 本文件门槛全部通过 | 记录通过依据，再执行其余质检及交付包检查；全部五道质检通过后才按 SKILL.md 标“可发布” |

“禁止发布”是阻断结论，核心交付状态仍沿用草案、待确认、可发布；存在阻断项的交付包可列为“待确认｜当前版本禁止发布”。修正后逐图/逐尺寸/A/B复核，不能只检查改过的主标题。实际上传、发布或投放仍需明确授权；设计检查通过不自动执行这些操作。
