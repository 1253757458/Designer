# 平台动态适配与规格核验

平台、商品类目、经营形态、使用位置和投放产品共同决定要求。淘宝不自动沿用天猫要求，商品主图不自动沿用内容封面或付费广告规范。本文件提供设计建议和官方核验入口，不固定当前像素、比例、安全区、张数或文件限制；每次具体交付重新核验。

## 核验与适配步骤

1. **确定适用对象**：记录商品是出版物、软件题库还是培训服务；确认平台、类目、店铺类型、场景及素材槽位。先查是否可售及资质要求，再查图像规格；不能靠视觉包装跨过准入限制。
2. **取得当前官方依据**：从上方入口进入正式规则和实际发布页，检查是否现行生效、有无新版、是否适用于该类目和槽位。历史通知、公示/征集、已失效版本及二手转载不作为当前要求。
3. **填规格记录**：记录页面标题、URL、规则版本/生效日期、访问日期与具体条款；把强制要求、后台校验提示、设计建议分别标清。官方页与后台提示冲突时保存双方依据，查最新正式规则或官方答复；未解决项保持待确认，不自选旧数字放行。
4. **重组信息**：保留五种主图功能、详情页必要事实和唯一 CTA，按该场景调整先后、标题密度、证据位置和模块分切。比例变化时重新排版；裁切不能丢掉价格条件、截图/示意图标签或购买限制。不能只放大缩小通用图。
5. **预览并导出**：按已核验槽位建画布，放回实际卡片/页面尺寸预览，检查裁切与控件覆盖，再检查全尺寸中文/数字。记录导出像素、格式、体积、命名和对应规则；平台再次压缩后有可用预览时复查。后台校验通过也不替代真实性/权利/广告检查。
6. **标注交付状态**：规格或准入未核实则提供草案和具体未决项，不能标可发布；已核验记录只对本次商品、场景、版本和日期负责。更换平台、类目、槽位、活动或再次交付时重新核验，保留旧记录用于追溯。

规格检查和平台预览是设计工作；上传、发布、报名活动或开始投放仍需已有明确授权。
