# 教育电商视觉系统

围绕真实商品和购买任务选择一种主方向。品牌要求优先；通用风格不能替代真实封面、界面与资质。四种方向是设计选项，不暗示商品具有相应机构身份或保证学习效果。

## 四种方向

下列色值是可调整的设计起点，不是平台标准。把颜色分配为背景、主文字、品牌主色和强调色，整组素材保持角色一致；强调色只服务一个焦点或主要行动。

| 方向 | 使用条件 | 配色角色示例 | 排版与图像策略 | 需避免 |
| --- | --- | --- | --- | --- |
| 可信专业 | 数字题库、职业考试商品需要清楚呈现内容和使用方法 | 背景 `#F5F7FA`；文字 `#182333`；主色 `#2459A6`；强调 `#C35416` | 稳定网格、中等字重、真实界面局部配功能说明 | 用蓝色、公章或徽章制造官方/考试机构关系 |
| 效率冲刺 | 已确认的考前复习场景、限时活动或精简学习路径 | 背景 `#FFF7ED`；文字 `#262626`；主色 `#AC3426`；强调 `#F2C94C` | 短标题、明确步骤、少量斜向或节奏图形；活动条件完整 | 保证提分、虚假倒计时、所有模块都用警示色；浅黄承担小字号正文 |
| 轻松陪伴 | 基础练习、自学、长期复习，用户需要低负担的阅读 | 背景 `#F4F7F0`；文字 `#243D34`；主色 `#356C59`；强调 `#B45B2E` | 较宽留白、简洁插画与真实产品并列、温和圆角 | 幼稚装饰掩盖商品，虚构老师/学员人物，低对比浅色正文 |
| 权威出版 | 已证实的纸质出版物或资料，封面与版本是购买依据 | 背景 `#F3EFE6`；文字 `#252825`；主色 `#334B3B`；强调 `#A64B35` | 真封面/内页为主，标题可用宋体，正文用清晰黑体 | 伪造出版社、ISBN、封面、印章或认证；把数字商品做成虚构纸质书 |

选方向时写一句原因，例如“受众需要判断科目和版本，先保证商品与范围可识别”。内容平台可以加入真实使用场景和阅读钩子；货架主图先突出商品与核心价值。跨平台保留品牌识别，按阅读情境重组，不只裁切。

## 中文字体：许可先于风格

选择标准：覆盖实际简体中文、数字、拉丁缩写、标点和考试符号；字面清楚、笔画缩小后不粘连；有真实可用字重；数字与正文协调；输出工具正确渲染。用实际商品名、长科目名、价格与“￥、%，（）”试排，检查缺字与异常回退。

可选例子仅限已核验发布者许可的字体，具体使用时仍记录下载版本、来源及许可证：

- **Noto Sans CJK SC**：适合正文、界面说明和短标题；官方 [Sans 许可证](https://raw.githubusercontent.com/notofonts/noto-cjk/main/Sans/LICENSE) 为 SIL Open Font License 1.1。
- **Noto Serif CJK SC**：可用于出版方向标题；官方 [Serif 许可证](https://raw.githubusercontent.com/notofonts/noto-cjk/main/Serif/LICENSE) 为 SIL Open Font License 1.1。

以上于 2026-10-07 核验，允许依许可作商业设计使用；字体文件单独出售、修改命名与再分发存在限制。若随源文件交付字体软件，按许可保留版权与许可文本。成品中使用字体与分发字体文件分开检查。用户指定其他字体时索取覆盖预定商业用途的授权依据；电脑已有、系统附带或名字相似均不证明许可。

## 字号层级与中文排版

一屏以主标题、支持信息、说明三个层级起步；必要的价格条件和购买限制必须可读。主标题约为支持文字的 1.5–2 倍、支持文字约为说明的 1.2–1.5 倍，可作为试排起点，最终由平台展示尺寸测试决定，不写成固定像素门槛。

标题靠字重、字号和位置形成焦点，避免同时依赖描边、阴影、渐变与多种装饰。中文按语义分行，不把年份、科目词组、价格及其条件拆散；标点避免不自然地孤立在行首/末。正文保持自然宽度和行距，不能靠压扁字形、极端缩字距或把说明缩到不可读来塞满内容。常用一套正文家族，第二套仅用于明确的标题角色；以实际输出检查字重，不伪造粗体效果。

## 网格、留白与对比

- **网格**：先划出商品、标题、证据与行动区，统一边距和对齐线；多张图沿用角色位置。详情页以模块网格呈现一段论证，模块之间用留白标示转换。安全区取当前平台规范，不从配色示例或跨境模板推断。
- **留白**：围绕主要焦点留连续空间；删减次要信息优先于无限加小字。必要说明与活动条件靠近对应数字/权益，避免与价格分离导致误解。
- **对比**：正文和说明选清楚的明暗对比，在实际背景上测试；亮色更适合面积小的强调。信息差异同时用文字/大小/位置表达，不能只依靠红绿等颜色差别。
- **一致性**：同组文字样式、圆角、线条、标签和阴影统一；商品真实颜色保留。A/B 只改声明变量，不能顺手调整强调色或按钮。

## 商品与背景分离

先检查真实资产质量和授权。通过边缘明暗、背景留白、局部简化或合理柔和阴影让商品轮廓清楚；不改变商品原色、封面内容、题目或界面事实。截图保持界面比例与真实名称，必要时突出局部并说明展示范围；扫描页和实拍分别标记，避免制造资产来源错觉。

ImageGen 用于背景、场景或原创辅助图形，不能补造“真实截图”、教材封面、证书和评价。长中文与关键数字后期独立排版；场景、插画与真实资产视觉地位有区分。缺少真实商品资产时使用明确标注的占位草案，不能用逼真的 AI 书封/界面冒充商品。具体生成与组合方法见 [image-generation.md](image-generation.md)。

## 缩略图与成品测试

1. 按目标平台实际卡片/信息流预览尺寸缩小查看，检查商品名与核心卖点可识别；尚未核验展示情境时注明预览假设。
2. 短暂查看后回答“卖什么、适合谁、核心价值是什么”；答不出则减信息并重排焦点，不能据此宣称转化已验证。
3. 回到全尺寸检查中文、数字、标点、行距、条件说明与真实资产；缩略图通过不替代细节检查。
4. 查看整组缩略图：任务是否重复，商品是否一致，证据/购买须知是否缺位；比对 A/B 实际差异。

## 常见失败与修正

| 失败 | 修正 |
| --- | --- |
| 红底黄字覆盖所有模块，标题和价格同时争抢焦点 | 保留一个主焦点，重新分配文字/背景/强调色角色 |
| 五张主图均为封面/内页展示 | 按购买任务补内容范围、使用价值、真实证据和交付须知 |
| 背景纹理穿过小字、商品边缘融入背景 | 文字区简化，增加轮廓与背景分离；逐尺寸检查 |
| “权威”靠假徽章、机构 Logo 或伪造封面 | 移除无依据身份表达，只用真实商品和可用证据 |
| 价格很大、条件和有效期小到不可读 | 将条件靠近权益，并给足字号和对比；删减装饰 |
| 用 AI 直接画长中文，错字后仍交付 | 改为独立中文排版，逐字与事实表核对 |
| 字体回退、缺字或未确认商业许可 | 换成覆盖字集且许可可追溯的字体，再检查导出 |

上述测试只验证视觉与信息表现；正式交付仍执行 [quality-assurance.md](quality-assurance.md) 的五道质检。
