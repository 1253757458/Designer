# 五道质量门槛与交付检查

检查对象是导出后的真实文件，包括每张主图、每个详情模块/分切、每个海报、每个平台尺寸和 A/B 两版。准备策略表、制作卡、事实表、资产授权台账、平台规格记录及原件，按以下顺序检查并留证。没有打开实际产物时，只能检查方案，不能填写成品通过。

## 检查记录与最终判定

每个版本建立一条记录，五道门槛分别填“通过 / 未通过 / 待核验”，不适用的子项写理由并留依据；不以空白等同通过。

```text
交付物/图或模块编号 | 文件名/版本/平台槽位/尺寸 | 门槛 | 核对项 | 证据或预览位置 | 结果 | 问题与修正动作/所需材料 | 责任人 | 检查日期 | 复核结果
```

五道门槛全部通过且交付包完整才标“可发布”。任何未通过或待核验项都阻断该文件和受影响版本，不能平均打分、只检查 A 版、只检查最大尺寸或靠备注放行。修改事实、文案、素材、比例或压缩后重新检查受影响门槛及导出文件；事实/素材共用时追踪所有引用位置。

## 1. 信息准确

| 要核对什么 | 操作与通过条件 | 失败后的处理 |
| --- | --- | --- |
| 名称、科目、年份、题量、版本与商品形态 | 对照 [compliance.md](compliance.md) 事实矩阵逐项核对落图值、对应 SKU/版本、依据与确认人；同组、详情、海报、A/B 一致，题量统计口径不混淆 | 不确定值删除或留明确占位草案；关键购买事实未确认则待确认，不自行补全 |
| 内容、功能、教师、资质、评价、数据与证据 | 每个主张指向真实依据；比对原始封面、内页、题目、截图和数值，资产类型/展示范围/演示数据标注准确 | 错配或改写证据则恢复原件；虚构内容立即移除，不能用生成输出自证 |
| 价格、赠品、截止、交付、服务与售后 | 对照活动表、当前商品条款，逐项核对值、起算规则、时区、SKU、人群与限制；条件就近可读，不因裁切丢失 | 重新核实并同步所有引用版本；无依据紧迫性移除，关键条款未决则待确认 |

通过证据：逐项事实编号与导出位置的核对表，以及真实资产/版本比对结果。不能只写“文案正确”。

## 2. 转化清晰

检查信息是否帮助购买判断，不把可读性测试称为点击/购买效果已验证。

| 对象 | 操作与通过条件 | 失败后的处理 |
| --- | --- | --- |
| 单张/单屏 | 短暂浏览后能复述卖什么、适合谁、单一核心价值；一个第一焦点，一个主要任务，必要条件不被口号遮住 | 删重复信息、重排层级；不了解商品形态时先补事实，不用道具暗示 |
| 主图组 | 按 [deliverable-playbooks.md](deliverable-playbooks.md) 覆盖表检查识别、内容、价值、信任、决策均有承载位置；新增图有增量问题 | 合并重复封面/内页，补真实使用价值与购买须知；缺证据保持待确认 |
| 详情页 | 每模块回答一个购买问题，前文主张有对应证据，必要范围/适用边界/交付/有效期/售后完整；滚动节奏测试通过 | 合并无价值段，补证据位置和标题接续；必要事实不能因缺材料而消失 |
| 活动海报与 A/B | 主题、适用商品、活动机制/条件与一个 CTA 清楚；承接匹配。A/B 有命名变量、实际差异表和指标，只有该变量变化 | 调整焦点与 CTA；多出配色、按钮或背景差异则回母版修正，或注明探索性对比 |

通过证据：预览条件、测试者实际复述、功能覆盖表/模块顺序、CTA 与承接核对、A/B 差异结果。测试者可为检查人；自检注明身份，不伪造真实用户测试。

## 3. 视觉可靠

| 要核对什么 | 操作与通过条件 | 失败后的处理 |
| --- | --- | --- |
| 中文与图像 | 完成下方逐字检查；对照原件核对商品轮廓、颜色、比例、Logo、封面/界面与证据；无生成漂移、乱码或虚构证据 | 改为后期文字和真实商品层；替换不合格生成图，重新导出 |
| 层级、对比、网格与整组一致性 | 主标题/支持/说明可辨，条件正文在实际背景可读；整组主体、色彩、光线、样式和视觉锚点一致 | 简化纹理/装饰、调整对比与留白；不以无限缩小文字解决拥挤 |
| 实际展示与裁切 | 主图缩略、详情滚动、海报三秒、逐尺寸裁切检查全部通过；透明素材实际 alpha/边缘正确，无压缩模糊 | 按槽位重新排版或换清晰原件；不得生成式补写真实题目或数值 |

通过证据：实际导出全尺寸检查、各目标预览、问题修正前后记录；仅描述配色或只看设计工具画布不足。

## 4. 权利完整

逐层对照 [compliance.md](compliance.md) 的授权台账，保持字段与四种状态原词，不另造授权状态。核对字体各字重、图标、图片、商品封面/内页/试题、截图内嵌作品、肖像/个人信息、品牌/商标和 AI 输入/输出；同时查本次渠道、地区、期限、修改、署名、生成输入与源文件再分发范围。

| 台账状态 | 通过/阻断与操作 |
| --- | --- |
| 已核验可商用 | 原件证据覆盖本次具体用途、许可条件已履行，才通过该资产的权利子项；不代替事实与广告判断 |
| 限制使用 | 当前用途限制未满足/未核验则阻断；履行并复核后更新为已核验可商用，保留限制和变更记录，或换素材 |
| 待补证 | 阻断该素材进入正式成品；取得授权原件或替换，不把口头保证、搜索结果当证明 |
| 禁止使用 | 移除/替换，含该资产的当前版本禁止发布；不能加免责声明放行 |

AI资产记录工具、日期、提示与输入/输出位置、当时商业条款和第三方相似性检查；生成允许商用不等于输入/输出全部权利无疑点。真实人物上传生成服务的许可与广告肖像许可分别核验。通过证据为完整台账、许可/授权存档、成品署名检查及源文件/字体分发范围结论。

## 5. 合规可交付

| 要核对什么 | 操作与通过条件 | 失败后的处理 |
| --- | --- | --- |
| 整幅广告与商品准入 | 按实际商品形态与适用范围执行合规文件，检查文字、图像、徽章、教师/学员、成绩与小字共同表达；无结果保证、考试参与暗示、禁用推荐证明或虚构事实，准入已核验 | 确认禁用则当前版本禁止发布，删除/重写/替换后重检；补证据或授权不能解除广告禁限。适用性未决则待确认 |
| 平台规格与发布场景 | 对照 [platform-specs.md](platform-specs.md) 的逐槽位记录，核验当前官方规则、日期/版本、比例像素、格式/体积、文字/导流、安全区、AI标识；导出实值匹配 | 缺正文、登录受限或条款冲突则列待补材料，不套历史通知、竞品尺寸或跨境模板 |
| AI与证据标签 | 图内截图/概念/演示数据标签就近可读；按适用规则保留生成标识并记录平台声明方法，合成、裁切及导出后复查 | 标签被删/遮挡则修正；规则未知保持待确认，示意标签不能代替 AI 声明/标识流程 |
| 交付一致与完整 | 所有文件可打开，顺序、尺寸、版本、状态可对应；交付清单完整，源文件能编辑或提供真实结构化说明，风险闭环 | 补齐缺文件/说明、重导出、修正状态；不把扁平图称可编辑文件 |

通过证据为整幅广告判断、规格记录及导出实值、AI处理记录和完整交付索引。可发布只表示本次五道检查通过，不保证平台审核通过；实际上传、发布、投放仍须明确授权。

## 必做的展示与文字测试

### 主图缩略测试

按目标卡片的实际显示尺寸放入预览，记录平台/槽位、设备/预览方式、显示尺寸依据；无法取得时注明假设，不能充当正式规格核验。单张短暂查看后写出商品名称/形态与核心价值，必要年份/版本/适用范围可辨；整组查看覆盖任务与商品是否一致。失败则删装饰、减非必需信息或重排，不删除关键条件。缩略通过后仍检查全尺寸证据与文字。

### 详情页滚动节奏

在目标移动端阅读宽度从首屏滚到底，按屏记录“这一屏的问题/结论/证据/下一屏承接”。标题连续、段落可扫读、商品事实和证据相邻，无重复空屏或连续密字堆积；必要说明不跨屏孤立。逐分切检查接缝、图序和内容无遗漏/重复。长图压缩或平台二次处理有可用预览时复查；缺真实预览记录限制。

### 海报三秒测试

按目标场景显示成品，看三秒后隐藏；检查人记录主题/商品、适用对象或活动边界、主要价值与下一步。能复述且只有一个 CTA 才通过。再打开核对完整价格/活动条件/截止/赠品/服务。三秒测试不要求读完所有条款，也不能据此隐藏条款；复述错误则重排主题、商品和行动层级，不制造虚假紧迫性。

### 错字与关键数字检查

逐行、逐字对照已核验文案与事实表，优先查商品名、考试/科目、年份、题量、价格、小数点/单位、截止时间/时区、有效期、服务与售后；再查标点、缺字、乱码、异常字体回退、语义换行、上下标和符号。OCR可辅助发现问题，不能替代人工对照，OCR推测与模型纠错都不是事实。证据内原文对照原件，发现本身疑点回源核实，不擅自改题目/分数。导出后再打开检查，每个版本留核对结果。

### 裁切与导出检查

按每个已核验槽位的裁切、圆角、控件与安全区预览；商品识别、关键条件、截图/概念/AI标签和 CTA 均保留且可读。比例改变重新布局，不直接裁掉说明。打开实际导出核对像素、比例、格式、体积、压缩质量、图序与透明性；白底与透明版本有清楚用途。尺寸建议与平台强制规则分别记录。

## 文件命名与交付包

统一采用 `项目_商品SKU-版本_平台-槽位_交付物-序号_宽x高_AB或NA_v版本_状态.扩展名`，例如 `qbank_SKU01-2027_平台-商品主图_main-01_1200x1200_A_v03_草案.png`；示例像素仅演示命名，不是平台标准。A/B 不适用时用 NA，详情分切带段/片序号。原件、生成素材、母版、导出和预览分目录，索引引用实际文件名；禁止未核验文件叫“可发布”，不覆盖原件，不混入废弃版本。

| 必交项 | 完整判定 |
| --- | --- |
| 成品与尺寸版本 | 文件索引列平台/槽位、图序/模块、尺寸/格式/体积、版本、五道结果和交付状态；实际文件逐一可打开 |
| 可编辑源文件或结构化版式说明 | 有源文件则检查层与文字；不能产出时提供完整文案、层级、坐标/尺寸、色值、字体/字重、素材路径、图序及导出设置，不虚报源文件 |
| 原始商品资产与使用清单 | 资产编号对应商品/SKU/版本、原件位置、展示范围与修改/脱敏记录；交付素材本体仅限许可允许范围 |
| 生成与合成记录 | 最终入选背景/辅助元素、提示合同、编辑目标/引用角色、固定锚点、实际输出、生成区域及标识处理记录 |
| 文案与事实依据表 | 每个主张对应值、依据/版本、确认状态、落图位置；活动/服务条件同步全部版本 |
| 素材来源与授权清单 | 完整授权台账、原始证明与署名/限制履行记录；字体/源素材再分发权限单独核验，不能交付禁止再分发素材 |
| 规范与检查表 | 当前逐槽位规格、官方来源与核验日期、广告判断、五道记录及实际预览；只保存必要脱敏证据 |
| A/B与观察指标 | 命名变量、完整A/B值、固定项、实际差异验收、假设与统计口径；多变量注明探索性，未实测不宣称提升 |
| 风险与待确认项 | 用合规文件风险字段列出所需材料/修正动作、责任人、受影响文件、复核结果；已解决记录保留，当前未决单独可查 |

只有全部五道通过且以上清单完成，才将对应版本列入可发布目录。策略/占位版式标“草案”；缺事实、授权、规格或必要选择标“待确认”。已有禁用内容/禁止资产而未修正时标“待确认｜当前版本禁止发布”，保留阻断结论，不能以用户接受风险替代修正。交付总览列每个文件状态，有一版通过不能给整个混合包标可发布。
