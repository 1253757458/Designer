# 原生 ImageGen 生产与中文合成

输入沿用 [intake-and-strategy.md](intake-and-strategy.md) 的事实/资产编号、策略表和 A/B 合同，视觉锚点取自 [education-visual-system.md](education-visual-system.md)，制作卡取自 [deliverable-playbooks.md](deliverable-playbooks.md)。先核验真实商品与生成输入的权利，再决定哪些区域适合生成；工具输出不是商品事实或授权证明。

## 按资产角色选择生产方式

| 任务 | 输入与生产方式 | 验收与边界 |
| --- | --- | --- |
| 新生成背景/场景 | 用已确认视觉方向写无商品、无文字背景提示，通过原生 `image_gen` 生成；留出真实商品与文字位置 | 场景只辅助表达学习情境，不虚构商品配件、交付内容或实际用户体验；缺真实商品资产时只能做背景/占位草案 |
| 编辑用户提供图片 | 查看目标，明确要改的区域与必须保留的区域；使用原生 `image_gen` 并包含每张编辑目标；保留原件，另存版本 | 逐项比对商品与原图；不把用户提供等同于已授权，不将编辑后画面称作未经处理的实拍 |
| 保持商品主体一致 | 首选独立生成背景，再合成同一真实商品原始资产；各图引用相同商品/SKU、版本及资产编号 | 封面名称、Logo、形状、颜色、题目、界面、数值与真实资产一致；提示中的“不改商品”不是保证，发生漂移则弃用该输出并回到原始资产合成 |
| 生成辅助元素 | 生成原创插画、抽象学习场景或装饰，独立成层；透明素材明确要求真实透明背景 | 不承担真实教材、试题、界面、资质、评价、教师身份或学习成绩的证据角色；简单流程/几何形用可编辑图形制作更易核对 |
| 包含中文排版的最终合成 | 将真实商品、生成背景/辅助层与已核验文字分层组合；长中文、关键数字、活动条件与证据型信息后期独立排版 | 逐字与事实表核对，缩略与全尺寸均检查；不因图像模型能画文字就把价格、题量、年份、资质或题目交给模型重写 |

真实封面、内页、试题、截图、证书或评价缺失时，索取真实可用资产或在草案图内标“待补真实资产，仅供版式确认”。不得用图像模型补造并冒充真实证据，也不得生成所谓“示例好评”“示例证书”填充信任区。概念图只解释概念，不占用真实证据槽位；界面概念图就近可读标“概念示意图，非实际产品界面”，裁切后保留。真实截图、扫描页与实拍沿用原始类型称谓，演示数据的标注沿用执行手册。

## 原生工具调用合同

执行时读取当前原生 `image_gen` 工具说明，以当时暴露的参数为准。这里使用当前工具的 `prompt`、`transparent_background`、`referenced_image_paths`、`num_last_images_to_include`；不虚构 `size`、`quality`、`n`、`mask`、`seed`、输出目录等原生参数。画布比例、构图和留白写进提示，返回后检查实际尺寸，按已核验平台要求排版和导出。

1. **先看输入**：本地图片先用 `view_image` 检查；附件/对话中的图片先实际查看。每张登记为编辑目标、风格参考或辅助合成输入，并核对版本、清晰度、隐私与 [compliance.md](compliance.md) 的生成输入权限。没有看到图片不能声称已检查。
2. **新生成**：全新背景/场景使用 `prompt`，不传 `referenced_image_paths` 或 `num_last_images_to_include`；把已确认色彩与构图写成文字约束。需要修改现有画面、保留其中主体时归为编辑，不能只写“请参考原图”却没有包含目标。
3. **编辑目标全有本地路径**：先查看，随后用 `referenced_image_paths` 传入每张目标及必要辅助图的实际路径；提示按输入顺序注明角色，不从文件名推断图片内容。
4. **至少一个编辑目标无本地路径**：使用 `num_last_images_to_include`，取能够覆盖所有目标的最小近期图片数量，上限为 5；提示按图序说明各自用途。两种引用机制不能同时传。若任一种都无法覆盖全部目标，要求重新附上缺失图片，暂停该编辑，继续不依赖该图片的工作；不能悄悄遗漏目标。
5. **透明背景**：用户要求抠图、去背景、透明辅助元素时设置 `transparent_background: true`，同时提示要求真实 alpha；其他新图为 `false`。编辑保留原有透明性，除非用户要求改变；用透明棋盘/深浅底预览验证 alpha 与边缘，不把画出的棋盘当透明。
6. **调用与返回**：生成与图像编辑使用原生 `image_gen`。生成可能需要数分钟；当前 code-mode 用首行 `// @exec: {"yield_time_ms": 120000}` 给首次调用等待时间，后续按当前工具说明用同样等待设置，勿把长等待误判为失败。完成后用 `generatedImage(result)` 展示，不打印整份 base64。记录返回的实际文件位置；若只有预览而未取得可用文件，不能称文件已保存。
7. **保存与迭代**：原生工具默认输出在 Codex 管理目录，不能承诺提示中的路径就是输出目录。选中项目素材后复制到用户指定目录或项目交付目录，采用版本名；不覆盖原件。一次调整一个明确问题，复述固定锚点并重新查看结果；问题持续时改用独立背景加真实资产合成。

批量交付按资产/变体分别调用，保存最终入选图及提示记录；A/B 仅改文字时共用同一背景与商品层，不能重新生成两套背景引入额外变量。工具不可用或返回失败时如实记录，可继续策略、中文和版式准备；不能声称生成成功，不能静默切换外部网关、CLI/API 或要求原生用户提供 API Key。

## 生成提示合同与同组锚点

每份提示保留以下字段；不适用项写明原因，如独立背景的商品锚点为“商品不进入模型，后期使用资产 P01”。事实、规格未核实则写为草案假设，不包装成平台要求。

| 字段 | 内容与核验方式 |
| --- | --- |
| 画布比例 | 已核验目标槽位比例或注明草案比例；最终像素取规格记录，实际输出另测 |
| 主体 | 背景/场景/辅助物，或编辑目标图序、真实商品及资产编号；说明商品形态与非交付道具 |
| 构图 | 主体位置、尺度、视角、阅读顺序；商品/证据/CTA 的后期区域 |
| 视觉方向 | 已确认方向与媒介，如可信专业、原创简洁插画；不制造机构身份 |
| 光线/材质 | 光线方向、软硬、色温和材质；商品真实颜色与内容不得变化 |
| 留白区 | 明确区域及用途，保持低纹理/清楚对比，避免元素穿过小字区 |
| 品牌色 | 色值及背景、主色、文字、强调色角色；保留真实商品原色 |
| 禁止元素 | 无虚构文字、数字、封面、试题、界面、证书、评价、官方徽章、未授权 Logo/角色；无误导赠品 |
| 商品一致性锚点 | 固定资产/SKU/版本、轮廓/比例/原色、Logo/封面内容、界面与数值；具体改动边界 |
| 后期文字区 | 主标题、正文、条件说明、真实证据和 CTA 的区域；不让模型重绘关键文字，中文另成可编辑层 |

另记输入角色、改动范围、固定项与输出资产编号。建立“组编号 | 商品资产/SKU/版本 | 视觉方向 | 配色角色 | 光线/材质 | 构图网格 | 后期文字区域”的组级锚点；每张只变自己的主要任务，稳定主体、色彩、光线和视觉锚点。整组并排比对，发现漂移先修正，不能用各张单独好看来放行。

### 一份背景生成提示示例

以下为已确认视觉方向下的结构示例，比例与色值是设计假设；执行前替换为本项目记录，不是平台硬性规格。

```text
任务：为数字题库主图生成独立背景，不生成商品或文字。
画布比例：1:1，草案比例，正式导出以规格记录为准。
主体：简洁抽象学习场景，无人物、书本、设备或赠品。
构图：右下少量抽象几何，左侧与中央留作商品和标题区。
视觉方向：可信专业、克制的平面与柔和立体混合辅助视觉。
光线/材质：统一左上柔光，哑光表面，低纹理。
留白区：左上标题、中部真实商品、底部条件说明，保持连续低纹理区域。
品牌色：背景 #F5F7FA，主色 #2459A6，少量强调 #C35416。
禁止元素：不生成文字、数字、Logo、徽章、教材、试题、界面、证书或评价。
商品一致性锚点：商品不进入模型，后期使用同一已核验资产 P01，不改变形态、版本及内容。
后期文字区：标题、商品名、关键条件、CTA 独立排版；本图不含文字。
```

编辑提示沿用同一合同，再逐图写清“图1为编辑目标，只替换背景；图2仅提供已授权的辅助元素”等角色，以及每个不变项。合成失败时不降低商品一致性要求。

## 中文与真实证据合成、检查和交付

1. 按制作卡建已核验尺寸画布，分层放背景/原创辅助图、真实商品/证据、中文文字、条件/标签及 CTA。用真实原件置入证据区；清晰度不足则取更清楚原件或缩小展示范围，不用生成式补字恢复题目、封面或数值。
2. 使用许可已核验、覆盖实际中文与符号的字体。复制已核验文案，价格、题量、年份、活动截止、有效期及条件引用事实编号；保留可编辑文字，不能把图像模型猜出的文字转录为事实。
3. 对照原件检查封面/界面内容、商品轮廓、颜色和版本，核对每个字、数字、标点与语义换行。透明边缘、阴影、比例或标签误导时重新合成。
4. 跨比例重新布局，保证商品、条件和截图/概念标签可见；A/B 按声明变量比对文字、资产、样式、位置和叠图差异。文字变量共用母版。
5. 保存原始资产、生成入选输出、提示/引用/改动记录和合成层。AI资产按合规文件记录工具、日期、适用商业条款、输入权利、生成区域与标识保留情况；示意标签不能代替适用的 AI 声明/标识。
6. 进入 [quality-assurance.md](quality-assurance.md) 逐图、逐尺寸、逐版本检查。无可编辑源文件时交付结构化版式说明；单张扁平图不能声称是可编辑源文件。
